# ADR-0001: Roadmap source of truth

- Date: 2026-09-30
- Status: Accepted

## Context

The pre-project master document contains an older phase mapping that conflicts with the separately supplied Master Phase Roadmap v1.0 and phase-specific documents dated 2026-09-30.

## Decision

Use Master Phase Roadmap v1.0, Release Gates, and matching phase-specific documents as the normative delivery sequence. Legacy phase numbering is historical context only.

## Alternatives

- Follow the older pre-project numbering.
- Merge both numbering schemes ad hoc.

## Consequences

GitHub Issues, docs and future commits use Phase 0–12 from Master Roadmap v1.0. Conflicting legacy references are annotated or migrated instead of silently interpreted.
